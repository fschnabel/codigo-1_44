## Descripción:
CinePlus es una aplicación web diseñada para mostrar películas en cartelera, permitir la renta de títulos y ofrecer una experiencia interactiva al usuario mediante animaciones, validaciones y componentes dinámicos.

1. Navegación dinámica
2. Catálogo de películas
3. Modal de Trailer
4. Página de Detalle de cada película
5. Formulario de Contacto
6. Formulario de Renta
